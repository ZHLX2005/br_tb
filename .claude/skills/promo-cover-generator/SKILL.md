# Promo Cover Generator — 推广封面批量生成器

## 触发场景

- "帮我做视频封面"
- "生成推广图"
- "做几个封面方案让我挑"
- "需要 PPT 风格的展示图"
- "做封面，要醒目"
- "生成产品宣传物料"

## 输出格式

**单个 HTML 文件**，包含：
- 多个封面方案垂直排列
- 内嵌所有 CSS，零外部资源（无网络字体、无图片外链）
- 浏览器打开即可截图（`Ctrl+P` 打印或系统截图工具）
- 每个方案标注类型标签（如"方案 1 · 痛点钩子型 · 16:9"）

## 视觉风格：Neo-Brutalism（新粗野主义）

| 要素 | 规范 |
|------|------|
| 边框 | `2~3px solid #000`，所有元素必须有 |
| 阴影 | 硬偏移 `box-shadow: Xpx Ypx 0 #000`，无 blur |
| 圆角 | `0~2px`，保持几何锋利感 |
| 填充 | 纯色块，高饱和度 |
| 字体 | 粗体为主 `font-weight: 700~900`，系统字体栈 |
| 背景 | 暖白 `#F7F7F4` 或纯黑 `#111` |

**推荐配色**：cyan `#00C8FF`、coral `#FF4D6D`、lime `#C8FF00`、amber `#FFB800`、lavender `#B8A9FF`

**按钮/卡片物理感**：
```css
.btn {
  border: 2px solid #000;
  box-shadow: 2px 2px 0 #000;
  transition: all 0.1s ease;
}
.btn:hover  { transform: translate(-1px,-1px); box-shadow: 3px 3px 0 #000; }
.btn:active { transform: translate(1px,1px); box-shadow: none; }
```

## 平台比例要求

**必须同时提供两种比例**，方便用户按平台选择：

| 比例 | 尺寸 | 用途 |
|------|------|------|
| 16:9 | 960×540 | B站视频封面、个人空间封面、YouTube 封面 |
| 4:3 | 960×720 | B站首页推荐位、小红书封面、微信公众号 |

实现方式：`.cover-frame` 为 16:9 基础，`.cover-frame.ratio-43 { height: 720px; }` 覆盖。

## 8 种封面方案（必须全部提供，冗余供挑选）

| # | 方案 | 核心手法 | 适用场景 |
|---|------|---------|---------|
| 1 | **痛点钩子** | 直击用户痛点（收藏夹吃灰、进度为0），用刺眼的数字或标签制造焦虑 | 钩子型视频开头、痛点类内容 |
| 2 | **血条可视化** | 把抽象进度具象为游戏血条，黑底+荧光色对比极强 | 工具类、效率类产品 |
| 3 | **数据冲击** | 一个巨大的数字（如 0%、99%）占据画面中心，配合极简文案 | 数据向、成果展示 |
| 4 | **Before / After** | 左右对比卡片，Before 灰暗/After 高亮，功能价值一目了然 | 教程类、工具改造类 |
| 5 | **功能清单** | 四宫格/六宫格卡片，每个功能一个 icon+标题+一句话说明 | 产品发布会、功能介绍 |
| 6 | **情绪爽感** | 游戏通关感、成就徽章、满屏 stamp，激发多巴胺 | 情绪价值向、个人成长类 |
| 7 | **截图模拟** | 模拟真实浏览器/APP 界面截图，降低理解成本 | 工具类、需要降低认知门槛时 |
| 8 | **大字报** | 超大字号（100px+），3 行以内，信息密度极低但冲击极强 | 纯文字向、口号类、系列视频 |

## 文案撰写原则

1. **标题不超过 2 行**，每行不超过 8 个字
2. **数字优先**："0%"、"5门课"、"12个" 比形容词更有冲击力
3. **口语化**："看了几集就弃坑？" 比 "提升学习效率" 抓人
4. **CTA 简短有力**：最后一个大字方案留产品名
5. **副标题解释痛点**，主标题制造冲突

## 错误案例

| 错误操作 | 实际后果 | 正确做法 |
|---------|---------|---------|
| 只提供 16:9 一种比例 | 用户上传 B站首页推荐位（4:3）时封面被裁切变形 | 每个方案必须同时生成 16:9 和 4:3 两张 |
| 使用 Google Fonts `@import` | Chrome 扩展 popup 场景每次打开都要请求网络，明显卡顿 | 只用系统字体栈，零外部资源 |
| 使用渐变背景或柔和阴影 | 破坏 Neo-Brutalism 的视觉识别度，显得脏 | 纯色块 + 硬偏移阴影 |
| 封面少于 5 个方案 | 用户没有挑选空间，容易推翻重来 | 至少提供 8 种不同角度的方案 |
| 圆角超过 4px | 失去粗野主义的几何锋利感 | 统一 0~2px，或完全直角 |
| 文案全是形容词 | "强大的功能"、"优秀的体验" —— 无法产生记忆点 | 用数字、冲突、对比 |

## 执行流程

1. 明确产品/功能的核心卖点（1~3 个）
2. 根据卖点选择 8 种方案中最匹配的类型（允许一个卖点对应多个方案）
3. 生成 HTML，每种方案包含 16:9 + 4:3 两张
4. 告知用户直接用浏览器打开，滚动到对应方案截图

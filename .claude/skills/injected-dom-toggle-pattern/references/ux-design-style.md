# 边缘悬浮小部件 — UX 设计风格

和 `hover-reveal.md`（技术实现）配对：那篇讲**怎么写**，这篇讲**为什么这么设计**。

适用：注入到任意页面的边缘悬浮小部件——刷题侧边栏、视频进度条、阅读辅助条、快捷工具入口等「寄生」在宿主页面上的轻量 UI。

## 设计哲学：克制 + 分层 + 低成本

宿主页面不是你的，悬浮部件是「客人」。核心原则只有一条：

> **静止时让用户忘记你的存在；需要时一伸手就够得到。**

由此衍生四条决策准则。

### 准则 1：克制浮现（不主动打扰）

- **反模式**：hover 到边缘就「咣」展开 240px 大面板。用户只是鼠标飘过，没打算用你。
- **正解**：hover 只浮现一个极小的**入口**（40px 圆环级别）。浮现本身是「我在这儿」的轻量信号，不是「我要占用你的视线」。
- 大面积近场触发带（32px 宽、全屏高度）降低瞄准成本，但**入口本身小**，避免误触展开。

### 准则 2：入口单一职责（去装饰）

入口只做一件事：**当门把手**。不要往门把手上挂装饰。

| 放在入口上 | 问题 |
|-----------|------|
| 进度环/百分比 | 视觉噪声，用户不需要每秒看刷题进度 |
| 数字计数 | 信息过载，入口变重 |
| 多个小图标 | 选择困难，违背「单一意图」 |

- **正解**：入口只放一个极简标识（字母 logo、单个图标）。进度、统计这些**留在展开后的面板里**。
- 教训来源：圆环进度环被用户要求移除——「不需要在圆环上显示进度」。

### 准则 3：分层交互（动作分明）

把「接近」「打开」「关闭」拆成三层，每层一个明确动作：

| 层 | 触发 | 结果 |
|----|------|------|
| L1 接近 | 鼠标靠近边缘 32px | 入口滑入（opacity + right 动画） |
| L2 打开 | 点击入口 | 展开具体内容面板 |
| L3 关闭 | 点击面板外任意处 | 自动收回 |

- **不要混层**：别让 L1 直接跳到「展开面板」（准则 1），也别让 L2 承担「关闭」（用户点开就想用，不该一点就关）。
- 关闭走 L3（点击外部），**不强制找 × 按钮**。

### 准则 4：低关闭成本（关比开还容易）

- **反模式**：展开后只能点右上角 × 关闭，或只能再点一次入口关闭——两个细小目标，鼠标要精确定位。
- **正解**：点击面板外任何区域即收回。用户的「离开意图」（鼠标移开看别的内容）自然触发关闭，零额外操作。
- 关闭按钮仍保留，但它管的是**持久化隐藏**（`showXxx: false`，刷新也不出现），不是临时收起。临时收起 vs 永久关闭，两个语义别混。

## 视觉密度决策

### 入口（收起态）
- 极小：40px 左右
- 极简：一个圆 + 一个标识，无进度、无数字、无多图标
- 藏起：静止时 `opacity: 0` 且不可点，藏在边缘外（`right: -40px`）

### 面板（展开态）
- 适中宽度：240px。太窄装不下信息，太宽挤压宿主内容。
- 信息分层：标题/统计/搜索 → 推荐区 → 分类列表，从「概览」到「详情」。
- **双轨出口**：面板里放一个「打开全屏看板」按钮。轻量查一眼走小面板，深度操作走全屏页。满足两种信息密度需求。

### 动画
- 入口滑入：200-280ms。太快突兀，太慢显得迟钝、跟手。
- 不要给入口加 scale 弹跳——它是「浮现」不是「弹跳」，克制感会被破坏。

## 反模式速查

| 反模式 | 为什么糟 |
|--------|---------|
| hover 直接展开大面板 | 鼠标飘过即打扰，违反准则 1 |
| 入口塞进度/计数/多图标 | 入口变重，违反准则 2 |
| 只能用 × 关闭 | 关闭成本高，违反准则 4 |
| × 按钮做临时收起 | 混淆了「临时收起」和「永久关闭」语义 |
| 只有全屏页、没有小面板 | 轻量查询也要打开整页，过重 |
| 只有小面板、没有全屏入口 | 深度操作受限，信息密度不够 |

## 演进时间线（真实决策链）

这个风格不是一次设计出来的，是以下迭代逼出来的：

```
悬浮展开整面板（打扰）
  → 圆环按钮 + 点击展开（位置跑偏）
    → 圆环贴右 + 悬浮才显示（克制浮现）
      → 入口显示进度环（过载）→ 移除进度（单一职责）
        → 加点击外部收回（低关闭成本）
          → 加全屏看板按钮（双轨出口）
```

每一步都是对上一版打扰/过载/高成本的反向修正。**做边缘悬浮 UI 时，先按这四条准则搭骨架，能省掉大部分迭代。**

## 检查清单

- [ ] 静止时入口完全不可见、不可点
- [ ] hover 只浮现入口，不直接展开面板
- [ ] 入口 ≤ 40px，只含单一标识，无进度/计数
- [ ] 近场触发带 ≥ 32px 宽，覆盖全屏高度
- [ ] 点击入口才展开内容
- [ ] 点击面板外部自动收回（低关闭成本）
- [ ] × 按钮管永久隐藏，临时收起走点外部
- [ ] 提供「小面板」+「全屏页」双轨出口
- [ ] 入口滑入动画 200-280ms，无弹跳

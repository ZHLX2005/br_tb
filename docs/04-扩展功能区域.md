## 1. 当前使用的扩展区域

### 1.1 功能分布图

```
Chrome 扩展
│
├── 🖥️  Popup (popup/)
│   ├── 快速翻译
│   ├── 统计信息
│   ├── 设置开关
│   ├── OCR 配置
│   ├── 快捷键设置
│   └── 功能导航
│
├── 🌐  Content Scripts (content/)
│   ├── content.js - 翻译浮层、收藏功能
│   └── content-ocr.js - OCR 区域选择、结果展示
│
├── ⚙️  Background (backgrounds/)
│   ├── contextMenu.js - 右键菜单
│   ├── messageHandler.js - 消息处理
│   ├── storage.js - 存储管理
│   └── ocr.js - OCR 截图
│
├── 📄  独立页面 (modules/)
│   ├── favorites/ - 收藏列表
│   └── browser-bookmarks/ - 书签管理
│
└── 🔧  右键菜单
    ├── 翻译选中文本
    └── OCR 区域识别
```

### 1.2 Popup 区域

**位置**: `popup/`

**功能**:
- 快速翻译输入框
- 翻译结果显示
- 统计信息（今日/总计）
- 设置开关（自动翻译、右键菜单）
- OCR 设置（提示词、流式输出、快捷键）
- 收藏设置（快捷键）
- 功能导航按钮

**交互方式**: 点击扩展图标打开

**生命周期**: 关闭即销毁

**代码示例**:

```javascript
// popup/popup.js

// 翻译按钮
translateBtn.addEventListener('click', handleTranslate);

// 设置开关
autoTranslateToggle.addEventListener('change', saveSettings);

// 快捷键录制
ocrShortcutInput.addEventListener('click', startShortcutRecording);

// 导航按钮
ocrBtn.addEventListener('click', showOCR);
```

### 1.3 Content Script 区域

**位置**: `content/`

**注入页面**: 所有网页 (`<all_urls>`)

**功能**:

| 文件 | 功能 | 交互方式 |
|------|------|----------|
| **content.js** | 划词翻译、收藏快捷键 | 选中文本、按键 |
| **content-ocr.js** | OCR 区域选择 | 快捷键、Popup 按钮 |

**生命周期**: 页面加载时注入，页面关闭时销毁

**关键特性**:
- 访问页面 DOM
- 监听页面事件
- 修改页面样式
- 与 Background 通信

**代码示例**:

```javascript
// content/content.js

// 监听文本选择
document.addEventListener('mouseup', (e) => {
  const selection = window.getSelection();
  const selectedText = selection.toString().trim();

  if (selectedText) {
    // 显示翻译浮层
    showTooltip(rect.left, rect.bottom, selectedText, translatedText);
  }
});

// 监听快捷键
document.addEventListener('keydown', (e) => {
  if (isShortcutMatch(e, currentShortcut)) {
    addToFavorites(selectedText, window.location.href);
  }
});
```

### 1.4 Background 区域

**位置**: `backgrounds/`

**运行环境**: Service Worker

**功能**:
- 右键菜单管理
- 消息转发处理
- 数据存储协调
- OCR 截图获取

**生命周期**: 按需唤醒，空闲时休眠

**关键特性**:
- 无法访问 DOM
- 可使用所有 Chrome API
- 长期运行状态管理

**代码示例**:

```javascript
// backgrounds/contextMenu.js

export function setupContextMenu() {
  // 创建右键菜单
  chrome.runtime.onInstalled.addListener(() => {
    chrome.contextMenus.create({
      id: 'translateSelection',
      title: '翻译 "%s"',
      contexts: ['selection']
    });
  });

  // 处理点击
  chrome.contextMenus.onClicked.addListener((info, tab) => {
    if (info.menuItemId === 'translateSelection') {
      chrome.tabs.sendMessage(tab.id, {
        action: 'showTranslation',
        originalText: info.selectionText,
        translatedText: info.selectionText + 'x'
      });
    }
  });
}
```

### 1.5 右键菜单区域

**位置**: 右键菜单（系统级）

**功能**:
- 翻译选中文本
- OCR 区域识别

**特点**:
- 系统原生界面
- 可根据设置动态显示/隐藏
- 支持占位符 `%s`

**代码示例**:

```javascript
chrome.contextMenus.create({
  id: 'translateSelection',
  title: '翻译 "%s"',  // %s 会被替换为选中文本
  contexts: ['selection']
});
```

### 1.6 独立页面区域

**位置**: `modules/`

**访问方式**: 新标签页打开

**功能**:
- 收藏列表管理
- 书签浏览

**特点**:
- 完整的 HTML 页面
- 可使用 Chrome API
- 通过 `chrome.runtime.getURL()` 访问

**代码示例**:

```javascript
// 打开收藏列表
chrome.tabs.create({
  url: chrome.runtime.getURL('modules/favorites/favorites.html')
});

// manifest.json
"web_accessible_resources": [{
  "resources": [
    "modules/favorites/favorites.html",
    "modules/favorites/favorites.js"
  ],
  "matches": ["<all_urls>"]
}]
```

## 3. 可扩展功能区域

### 3.1 DevTools 扩展

**用途**: 开发者工具扩展

**场景**:
- 性能分析面板
- 网络请求监控
- 自定义审查器

**示例**:

```javascript
// manifest.json
{
  "devtools_page": "devtools.html"
}

// devtools.js
chrome.devtools.panels.create('My Panel',
  'icon.png',
  'panel.html',
  (panel) => {
    // 面板创建完成
  }
);
```

### 3.2 Omnibox 扩展

**用途**: 地址栏快捷命令

**场景**:
- 快速搜索
- 快捷操作
- 命令别名

**示例**:

```javascript
// manifest.json
{
  "omnibox": {
    "keyword": "ext"
  }
}

// background.js
chrome.omnibox.onInputEntered.addListener((text) => {
  chrome.tabs.create({ url: 'https://example.com/search?q=' + text });
});
```

### 3.3 Options 页面

**用途**: 扩展选项设置

**场景**:
- 详细设置界面
- 账户管理
- 高级配置

**示例**:

```javascript
// manifest.json
{
  "options_page": "options.html",
  "options_ui": {
    "page": "options.html",
    "open_in_tab": true
  }
}

// 右键菜单 → 选项
chrome.runtime.openOptionsPage();
```

### 3.4 通知 (Notifications)

**用途**: 系统级通知

**场景**:
- 重要提醒
- 状态变更
- 定时通知

**示例**:

```javascript
chrome.notifications.create({
  type: 'basic',
  iconUrl: 'icon.png',
  title: '翻译完成',
  message: '已翻译 5 个单词'
});
```

### 3.5 Badge 徽章

**用途**: 扩展图标上的数字/文字

**场景**:
- 未读计数
- 状态指示
- 快速信息

**示例**:

```javascript
// 设置徽章文字
chrome.action.setBadgeText({ text: '5' });
chrome.action.setBadgeBackgroundColor({ color: '#FF0000' });

// 设置徽章提示
chrome.action.setTitle({ title: '5 个待翻译' });
```

### 3.6 Context Menu 增强

**当前**: 翻译、OCR

**可扩展**:
- 图片操作（保存、压缩）
- 链接操作（复制、打开）
- 媒体操作（下载、播放）

**示例**:

```javascript
// 图片右键菜单
chrome.contextMenus.create({
  id: 'saveImage',
  title: '保存图片到收藏',

chrome.contextMenus.create({
  id: 'copyLink',

```

### 3.7 后台定时任务

**用途**: 定期执行任务

**场景**:
- 数据同步
- 定时提醒
- 缓存清理

**示例**:

```javascript

  periodInMinutes: 1440  // 24 小时

  if (alarm.name === 'dailySync') {

```

### 3.8 WebRTC 通信

**用途**: 实时通信

**场景**:
- 屏幕共享
- 语音通话
- 视频聊天

**示例**:

## 4. 扩展最佳实践

### 4.1 模块化设计

**原则**: 每个功能独立模块

**示例**:

```
modules/
├── favorites/          # 收藏功能
│   ├── favorites.html
│   ├── favorites.js
│   └── favorites.css
├── history/            # 历史记录
│   ├── history.html
│   ├── history.js
│   └── history.css
└── settings/           # 高级设置
    ├── settings.html
    ├── settings.js
    └── settings.css
```

**优势**:
- ✅ 便于维护
- ✅ 可独立开发
- ✅ 降低耦合

### 4.2 统一的配置管理

```javascript
// config/config.js

export const API_CONFIG = {
  baseURL: 'https://api.example.com',
  apiKey: 'YOUR_API_KEY',
  timeout: 30000
};

export const STORAGE_KEYS = {
  SETTINGS: 'settings',
  OCR_SETTINGS: 'ocrSettings',
  FAVORITES: 'favorites',
  STATISTICS: 'statistics'
};
```

### 4.3 统一的消息格式

```javascript
// utils/message.js

export const ACTIONS = {
  TRANSLATE: 'translate',
  ADD_TO_FAVORITES: 'addToFavorites',
  OPEN_FAVORITES: 'openFavorites',
  UPDATE_SETTINGS: 'updateSettings'
};

export function sendMessage(action, data = {}) {
  return new Promise((resolve) => {
    chrome.runtime.sendMessage({
      action,
      ...data
    }, resolve);
  });
}
```

### 4.4 错误处理

```javascript
// utils/errorHandler.js

export function handleExtensionError(error, context = '') {
  console.error(`[${context}] 错误:`, error);

  // 通知用户
  if (error.message) {
    chrome.notifications.create({
      type: 'basic',
      iconUrl: 'icon.png',
      title: '操作失败',
      message: error.message
    });
  }

  // 上报错误
  reportError(error, context);
}
```

### 4.5 性能优化

**减少 Content Script 体积**:

```javascript
// 按需注入
chrome.runtime.onMessage.addListener((request) => {
  if (request.action === 'injectOCR') {
    injectScript('content-ocr.js');
  }
});

function injectScript(scriptName) {
  const script = document.createElement('script');
  script.src = chrome.runtime.getURL(scriptName);
  document.head.appendChild(script);
}
```

**使用 Service Worker 缓存**:

```javascript
// backgrounds/cache.js

const CACHE_NAME = 'v1';

self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME).then((cache) => {
      return cache.addAll([
        '/modules/favorites/favorites.html',
        '/modules/history/history.html'
      ]);
    })
  );
});
```

## 5. 实际案例

### 5.1 添加历史记录功能

**步骤**:

1. 创建 `modules/history/` 目录
2. 创建 `history.html`, `history.js`, `history.css`
3. 更新 `manifest.json`
4. 在 `popup.html` 添加按钮
5. 在 `popup.js` 添加导航函数

**代码**:

```javascript
// manifest.json
"web_accessible_resources": [{
  "resources": [
    "modules/history/history.html",
    "modules/history/history.js"
  ],
  "matches": ["<all_urls>"]
}]

// popup.js
function showHistory() {
  chrome.tabs.create({
    url: chrome.runtime.getURL('modules/history/history.html')
  });
}

// backgrounds/messageHandler.js
} else if (request.action === 'getHistory') {
  chrome.storage.local.get(['history'], (result) => {
    sendResponse({ history: result.history || [] });
  });
  return true;
}
```

### 5.2 添加 Badge 计数

```javascript
// backgrounds/statistics.js

export function updateBadgeCount() {
  chrome.storage.local.get(['favorites'], (result) => {
    const count = result.favorites ? result.favorites.length : 0;

    if (count > 0) {
      chrome.action.setBadgeText({ text: count.toString() });
      chrome.action.setBadgeBackgroundColor({ color: '#6c757d' });
    } else {
      chrome.action.setBadgeText({ text: '' });
    }
  });
}

// 监听收藏变化
chrome.storage.onChanged.addListener((changes) => {
  if (changes.favorites) {
    updateBadgeCount();
  }
});
```

## 总结

### 当前功能矩阵

| 区域 | 已实现功能 | 可扩展方向 |
|------|-----------|-----------|
| **Popup** | 翻译、设置、配置 | 账户同步、主题切换 |
| **Content Script** | 翻译浮层、OCR 选择 | 页面标注、内容注入 |
| **Background** | 菜单、消息、存储 | 定时任务、数据分析 |
| **独立页面** | 收藏、书签 | 历史、统计、设置 |
| **右键菜单** | 翻译、OCR | 保存、压缩、转换 |

### 扩展优先级建议

| 优先级 | 功能 | 难度 | 价值 |
|-------|------|------|------|
| 🔥 高 | 历史记录 | 低 | 高 |
| 🔥 高 | Badge 计数 | 低 | 中 |
| 🔥 高 | Options 页面 | 中 | 高 |
| 中 | 通知提醒 | 低 | 中 |
| 中 | Omnibox | 中 | 中 |
| 低 | DevTools | 高 | 低 |
| 低 | WebRTC | 高 | 低 |

### 下一步建议

## 技术栈

- **扩展版本**: Manifest V3
- **模块系统**: ES6 Modules
- **存储**: chrome.storage.local
- **通信**: chrome.runtime.sendMessage
- **API**: 智谱 AI GLM-4.5V (OCR)

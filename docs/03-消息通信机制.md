## 1. 通信方式概览

### 1.1 Chrome 扩展架构

```
┌─────────────────────────────────────────────────────────────┐
│                    Chrome 扩展环境                           │
│                                                              │
│  ┌─────────────┐   ┌─────────────┐   ┌─────────────┐      │
│  │   Popup     │   │ Background  │   │  Content    │      │
│  │   (UI)      │◄─►│   (SW)      │◄─►│   Script    │      │
│  │             │   │  Service    │   │  (网页中)    │      │
│  └─────────────┘   │   Worker    │   └─────────────┘      │
│                    └─────────────┘                         │
│                           │                                 │
│                           ▼                                 │
│                    ┌─────────────┐                         │
│                    │   Storage   │                         │
│                    │   (数据)    │                         │
│                    └─────────────┘                         │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 通信方式对比

| 方式 | 方向 | 适用场景 | 特点 |
|------|------|----------|------|
| **chrome.runtime.sendMessage** | 双向 | 即时通信 | 需要响应 |
| **chrome.storage** | 间接 | 数据共享 | 自动同步 |
| **chrome.tabs.sendMessage** | Background → Content | 主动推送 | 指定标签页 |
| **chrome.runtime.onMessage** | 监听 | 接收消息 | 事件驱动 |

## 2. chrome.runtime.sendMessage

### 2.1 基本用法

**发送消息**:

```javascript
chrome.runtime.sendMessage(message, callback);
```

**接收消息**:

```javascript
chrome.runtime.onMessage.addListener((request, sender, sendResponse) => {
  // 处理消息
  sendResponse(response);
});
```

### 2.2 完整示例

#### Content Script → Background

**发送端** (Content Script):

```javascript
// content.js

// 发送翻译请求
chrome.runtime.sendMessage({
  action: 'translate',
  text: 'Hello World'
}, (response) => {
  if (response && response.success) {
    console.log('翻译结果:', response.translatedText);
  }
});
```

**接收端** (Background):

```javascript
// background.js

chrome.runtime.onMessage.addListener((request, sender, sendResponse) => {
  if (request.action === 'translate') {
    // 处理翻译
    const translatedText = request.text + 'x';

    // 发送响应
    sendResponse({
      success: true,
      translatedText: translatedText
    });
  }
});
```

### 2.3 异步响应

**异步操作需要返回 `true`**:

```javascript
chrome.runtime.onMessage.addListener((request, sender, sendResponse) => {
  if (request.action === 'performOCR') {
    // 异步操作
    handleOCRRequest(request).then(sendResponse);
    return true;  // 🔥 重要：表示将异步响应
  }
});
```

### 2.4 Broadcast (广播给所有)

**Popup 端**:

```javascript
// popup.js

function saveShortcut(shortcut) {
  chrome.storage.local.set({ favoritesShortcut: shortcut });

  // 广播给所有标签页
  chrome.tabs.query({}, (tabs) => {
    tabs.forEach(tab => {
      chrome.tabs.sendMessage(tab.id, {
        action: 'updateShortcut',
        shortcut: shortcut
      }).catch(() => {
        // 忽略无法发送消息的标签页
      });
    });
  });
}
```

**Content Script 端**:

```javascript
// content.js

chrome.runtime.onMessage.addListener((request, sender, sendResponse) => {
  if (request.action === 'updateShortcut') {
    currentShortcut = request.shortcut;
    sendResponse({ success: true });
  }
});
```

## 3. chrome.storage

### 3.1 基本用法

**保存数据**:

```javascript
chrome.storage.local.set({ key: value }, () => {
  console.log('数据已保存');
});
```

**读取数据**:

```javascript
chrome.storage.local.get(['key'], (result) => {
  console.log('数据:', result.key);
});
```

**删除数据**:

```javascript
chrome.storage.local.remove(['key']);
```

### 3.2 监听变化

```javascript
chrome.storage.onChanged.addListener((changes, areaName) => {
  if (areaName === 'local' && changes.key) {
    const oldValue = changes.key.oldValue;
    const newValue = changes.key.newValue;

    console.log('数据变化:', oldValue, '→', newValue);
  }
});
```

### 3.3 实战案例

#### 设置同步

**Popup 端**:

```javascript
// popup.js

function saveSettings() {
  const settings = {
    autoTranslate: autoTranslateToggle.checked,
    showContextMenu: showContextMenuToggle.checked
  };

  // 保存到 storage
  chrome.storage.local.set({ settings });

  // 同时发送消息（确保即时同步）
  chrome.tabs.query({}, (tabs) => {
    tabs.forEach(tab => {
      chrome.tabs.sendMessage(tab.id, {
        action: 'updateSettings',
        settings: settings
      }).catch(() => {});
    });
  });
}
```

**Content Script 端**:

```javascript
// content.js

// 方式 1: 监听消息
chrome.runtime.onMessage.addListener((request, sender, sendResponse) => {
  if (request.action === 'updateSettings') {
    settings = { ...settings, ...request.settings };
    sendResponse({ success: true });
  }
});

// 方式 2: 监听 storage 变化
chrome.storage.onChanged.addListener((changes, areaName) => {
  if (areaName === 'local' && changes.settings) {
    settings = changes.settings.newValue;
  }
});
```

## 5. 实战案例

### 5.1 OCR 通信流程

```
┌─────────────────┐    sendMessage    ┌─────────────────┐
│  Content Script │ ─────────────────► │   Background    │
│  (content-ocr)  │                    │   (background)  │
└─────────────────┘                    └─────────────────┘
       │                                         │
       │ 请求截图                                │
       │ { action: 'performOCR', rect: {...} }   │
       │                                         │
       │                  captureVisibleTab()    │
       │                                         │
       │ ◄──────────────────────────────────────│
       │ { dataUrl, rect }                       │
       │                                         │
       ▼                                         ▼
    cropImage()                           (处理完成)
       │
       ▼
    callOCRApi()
       │
       ▼
    showResult()
```

**代码实现**:

```javascript
// === Content Script ===

// 1. 发送 OCR 请求
chrome.runtime.sendMessage({
  action: 'performOCR',
  rect: { left: 100, top: 200, width: 300, height: 150 }
}, async (response) => {
  if (response && response.success) {
    // 2. 裁剪图片
    const croppedImage = await cropImage(
      response.dataUrl,
      response.rect
    );

    // 3. 调用 API
    const result = await callOCRApi(croppedImage);

    // 4. 显示结果
    showResultPanel(result);
  }
});

// === Background ===

chrome.runtime.onMessage.addListener((request, sender, sendResponse) => {
  if (request.action === 'performOCR') {
    // 异步处理
    handleOCRRequest(request).then(sendResponse);
    return true;
  }
});

async function handleOCRRequest(request) {
  const dataUrl = await chrome.tabs.captureVisibleTab(null, {
    format: 'png'
  });

  return {
    success: true,
    dataUrl: dataUrl,
    rect: request.rect
  };
}
```

### 5.3 收藏功能通信

**Content Script → Background**:

```javascript
// Content Script

function addToFavorites(text, url) {
  chrome.runtime.sendMessage({
    action: 'addToFavorites',
    text: text,
    url: url,
    timestamp: new Date().toISOString()
  });
}
```

**Background 处理**:

```javascript
// Background

chrome.runtime.onMessage.addListener((request, sender, sendResponse) => {
  if (request.action === 'addToFavorites') {
    chrome.storage.local.get(['favorites'], (result) => {
      const favorites = result.favorites || [];

      // 检查重复
      const exists = favorites.some(
        fav => fav.text === request.text && fav.url === request.url
      );

      if (!exists) {
        favorites.unshift({
          text: request.text,
          url: request.url,
          timestamp: request.timestamp
        });

        // 保持 200 条以内
        if (favorites.length > 200) {
          favorites.pop();
        }

        chrome.storage.local.set({ favorites });
      }

      sendResponse({ success: true });
    });

    return true;  // 异步响应
  }
});
```

## 6. 最佳实践

### 6.1 消息格式规范

```javascript
// ✅ 好的消息格式
{
  action: 'translate',        // 动作类型
  text: 'Hello',              // 数据
  options: {                  // 可选参数
    source: 'en',
    target: 'zh'
  }
}

// ❌ 不好的消息格式
{
  text: 'Hello',
  doTranslation: true,
  fromWhere: 'popup'
}
```

### 6.2 错误处理

```javascript
// 发送端
chrome.runtime.sendMessage(message, (response) => {
  if (chrome.runtime.lastError) {
    console.error('消息发送失败:', chrome.runtime.lastError.message);
    return;
  }

  if (response && response.success) {
    // 处理成功
  } else {
    // 处理失败
  }
});

// 接收端
chrome.runtime.onMessage.addListener((request, sender, sendResponse) => {
  try {
    // 处理逻辑
    sendResponse({ success: true, data: result });
  } catch (error) {
    sendResponse({ success: false, error: error.message });
  }
});
```

### 6.3 异步处理

```javascript
// ✅ 异步操作正确处理
chrome.runtime.onMessage.addListener((request, sender, sendResponse) => {
  if (request.action === 'asyncOperation') {
    // 方式 1: 返回 Promise
    doAsyncWork(request).then(sendResponse);
    return true;

    // 方式 2: 使用 async/await
    (async () => {
      const result = await doAsyncWork(request);
      sendResponse({ success: true, data: result });
    })();
    return true;
  }
});
```

### 6.4 避免消息丢失

```javascript
// ✅ 使用 try-catch 包裹
chrome.tabs.sendMessage(tabId, message, (response) => {
  try {
    if (response) {
      // 处理响应
    }
  } catch (error) {
    console.error('处理响应失败:', error);
  }
});

// ✅ 检查 lastError
chrome.tabs.sendMessage(tabId, message, (response) => {
  if (chrome.runtime.lastError) {
    // 标签页可能已关闭
    console.warn('发送失败:', chrome.runtime.lastError.message);
    return;
  }
  // 处理响应
});
```

### 6.5 性能优化

```javascript
// ❌ 不好的做法：频繁发送消息
document.addEventListener('input', (e) => {
  chrome.runtime.sendMessage({
    action: 'save',
    text: e.target.value
  });
});

// ✅ 好的做法：防抖
function debounce(func, wait) {
  let timeout;
  return function(...args) {
    clearTimeout(timeout);
    timeout = setTimeout(() => func.apply(this, args), wait);
  };
}

const debouncedSave = debounce((text) => {
  chrome.runtime.sendMessage({
    action: 'save',
    text: text
  });
}, 500);

document.addEventListener('input', (e) => {
  debouncedSave(e.target.value);
});
```

## 总结

### 通信方式选择指南

| 场景 | 推荐方式 | 原因 |
|------|----------|------|
| 需要即时响应 | `sendMessage` | 双向通信 |
| 数据共享 | `chrome.storage` | 自动同步 |
| Background → Content | `tabs.sendMessage` | 主动推送 |
| 大数据传输 | `chrome.storage` | 避免消息过大 |

### 关键要点

1. **异步处理**: 记得返回 `true`
2. **错误处理**: 检查 `lastError`
3. **消息格式**: 统一使用 `action` 字段
4. **性能优化**: 防抖、节流
5. **安全验证**: 检查消息来源
